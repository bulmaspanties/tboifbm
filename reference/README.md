# Reference art

Vanilla character and boss sprites from The Binding of Isaac, used as **reference only** while
designing Gridiron's art: sizing the roomy and horned helmets per character, and matching the
boss style for The Franchise. They are game assets owned by their creators, are **not** part of
the mod, and are never included in the release zip (`tools/package.py` only ships `content/`,
`resources/`, `scripts/`, `main.lua`, `metadata.xml` and `thumb.png`).
